# ICTマニュアルページ 要件定義書 v0.2

## 1. 概要

kiweb2内に、ICT関連の操作方法・トラブル対応・業務システムの使い方をまとめた「ICTマニュアルページ」を追加する。

利用者が困ったときに、担当者へ問い合わせる前に自分で確認できる場所を用意し、問い合わせ対応の負担軽減、説明内容の統一、新人・非常勤講師への案内効率化を目的とする。

初期実装ではDBや管理画面は用いず、PHPによるログイン確認、HTML / CSS / JavaScript / Markdown / JSON による軽量な構成で実装する。

## 2. 基本方針

- 既存の `teacher-auth` のログインセッションを利用する。
- マニュアルページ、一覧JSON、Markdown本文、画像は未ログインで直接閲覧できないようにする。
- DB管理、既読管理、管理画面編集は初期実装の対象外とする。
- Markdown本文はHTMLを直接書かなくても更新できる構成にする。
- 将来的に権限別表示、FAQ、アクセスログ、管理画面編集へ拡張できる余地を残す。

## 3. 想定ユーザー

### 3.1 非常勤講師

- kiweb2へのログイン方法
- 出退勤の打刻方法
- 授業予定・授業報告関連の操作
- 資料配信・PDFビューアの使い方
- よくあるトラブル対応

### 3.2 専任講師

- 非常勤講師向け情報
- 欠勤振替申請
- 勤務記録の確認
- 授業報告検索
- 会議室予約
- 専任向け機能の操作方法

### 3.3 管理者・ICT担当者

- 資料配信の管理方法
- サイネージ関連の操作
- アクセスログ確認
- ユーザー管理
- トラブル対応手順

管理者向け情報は `target: ["admin"]` を設定し、非常勤・専任ユーザーから本文を直接指定されても返さない。

## 4. 対象範囲

初期実装で対象とする範囲は以下とする。

- kiweb2内のメニューからICTマニュアルページを開けること
- ログイン済みユーザーのみ閲覧できること
- カテゴリ別にマニュアルを表示できること
- Markdownファイルを読み込み、HTMLとして表示できること
- Markdown内で画像を差し込めること
- PC・スマホの両方で閲覧できること
- マニュアルの更新日を表示できること
- タイトル、カテゴリ、説明文、タグで簡易検索できること
- 一覧に戻る導線を用意すること

初期実装では以下は対象外とする。

- DBによるマニュアル管理
- 管理画面からのマニュアル編集
- 既読管理
- コメント機能
- ファイルアップロード機能
- 本文全文検索
- アクセスログ集計画面

## 5. 機能要件

### 5.1 ICTマニュアル入口

`kiweb2.html`、`kiweb2-fulltime.html`、`kiweb2-admin.html` のメニューに「ICTマニュアル」への入口を追加する。

入口は iframe 表示先として `/kiweb/teacher-auth/public/ict-manual.php` を開く。

### 5.2 トップページ表示

ICTマニュアルのトップページには以下を表示する。

- ページタイトル
- 検索欄
- カテゴリ一覧
- マニュアル一覧
- 最近更新されたページ

### 5.3 カテゴリ

初期カテゴリ案は以下とする。

- ログイン・アカウント
- kiweb2基本操作
- 出退勤・勤務記録
- 授業予定・授業報告
- 欠勤振替申請
- 会議室予約
- 資料配信・PDFビューア
- サイネージ
- よくあるトラブル
- 問い合わせ方法
- 管理者向け

### 5.4 Markdown表示

マニュアル本文はMarkdownファイルで管理する。

画面表示時にJavaScriptで本文取得APIを呼び出し、画面側でHTMLに変換して表示する。

初期実装では安全性を優先し、Markdown内のHTMLはエスケープして表示する。将来的にMarkdownライブラリを導入する場合も、外部CDNではなくkiweb内に配置し、変換後HTMLをサニタイズする。

### 5.5 画像表示

Markdown本文内で画像を表示できるようにする。

画像は `teacher-auth/ict-manual/assets/images/` に配置し、直接URLではなくPHP経由で配信する。

Markdown内では次のように記述する。

```markdown
![ログイン画面](images/login/login-01.png)
```

### 5.6 検索

トップページに検索欄を設置する。

初期実装では以下を検索対象とする。

- タイトル
- カテゴリ
- 説明文
- タグ

本文検索は将来的な拡張対象とする。

### 5.7 詳細ページ表示

マニュアル詳細には以下を表示する。

- タイトル
- カテゴリ
- 更新日
- 対象ユーザー
- 本文
- Markdown見出しから生成した目次
- 一覧に戻るボタン

### 5.8 問い合わせ導線

各ページの末尾に、解決しない場合の問い合わせ先を表示する。

初期実装では固定文言とする。

## 6. 認証・権限

### 6.1 ログイン必須

ICTマニュアルページ本体、一覧JSON、Markdown本文、画像はすべてログイン必須とする。

未ログインで直接URLへアクセスした場合は、ログイン画面へ遷移するか、JSON/APIでは401を返す。

### 6.2 target制御

`manuals/index.json` の `target` で表示対象を制御する。

利用する値は以下とする。

- `all`
- `parttime`
- `fulltime`
- `admin`

初期実装でも、一覧表示と本文取得の両方で `target` を確認する。

### 6.3 管理者向け情報

管理者向けマニュアルには内部運用情報が含まれる可能性があるため、`target: ["admin"]` のアクセス制御を必須とする。

`.env`、DBパスワード、GAS URL、Slack token、FTP情報などの秘密情報は本文に記載しない。

## 7. ファイル構成

初期実装では以下の構成とする。

```text
/kiweb/
  docs/
    ict-manual-requirements.md
  teacher-auth/
    ict-manual/
      manuals/
        index.json
        login.md
        cache-refresh.md
        checkin.md
        pdf-viewer.md
        contact.md
      assets/
        images/
    public/
      ict-manual.php
      ict-manual-file.php
```

`teacher-auth/ict-manual/` は `.htaccess` で直アクセスを禁止する。

## 8. index.json仕様

```json
[
  {
    "id": "login",
    "title": "ログインできないとき",
    "category": "ログイン・アカウント",
    "file": "login.md",
    "description": "kiweb2にログインできない場合の確認手順です。",
    "updated": "2026-06-08",
    "target": ["all"],
    "tags": ["ログイン", "パスワード", "アカウント"],
    "priority": "high",
    "order": 10,
    "visible": true
  }
]
```

## 9. Markdown記述ルール

各Markdownファイルは以下の構成を基本とする。

```markdown
# タイトル

## 対象

このページの対象者を書く。

## 概要

このページで説明する内容を簡単に書く。

## 手順

1. 手順を書く
2. 必要に応じて画像を入れる
3. 注意点を書く

## 解決しない場合

問い合わせ先や次の対応を書く。
```

## 10. 受け入れ基準

- kiweb2のメニューからICTマニュアルページを開ける
- 未ログインで `ict-manual.php` を開くとログイン画面へ遷移する
- 未ログインで本文取得APIを呼ぶと401になる
- 非常勤ユーザーで `target: ["admin"]` の本文を直接指定しても閲覧できない
- ICTマニュアルのトップページが表示される
- カテゴリ別にマニュアル一覧が表示される
- 検索欄でタイトル・カテゴリ・説明文・タグによる絞り込みができる
- 一覧からマニュアル詳細を開ける
- Markdown本文がHTMLとして表示される
- Markdown内の画像がログイン済みユーザーに表示される
- Markdown内にHTMLやscriptがあっても実行されない
- PCとスマホで大きな表示崩れがない
- 更新日が表示される
- 一覧に戻る導線がある
- Markdown更新後にキャッシュの影響を避けて内容を反映できる
