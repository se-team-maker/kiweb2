# タイトルを書く

## 対象

このページを読む人を書きます。

例:

- kiweb2にログインできない利用者
- 出退勤記録を確認したい講師
- 資料配信を管理する管理者

## 概要

このページで説明する内容を短く書きます。

例:

kiweb2のログインでよくある原因と、問い合わせ前に確認する手順を説明します。

## 手順

1. 最初に行う操作を書きます。
2. 次に行う操作を書きます。
3. 最後に確認する内容を書きます。

## よくある原因

- 起こりやすい原因を書きます。
- 利用者が間違えやすい点を書きます。
- 事前に確認してほしい点を書きます。

## 注意点

- 操作前に知っておくべき注意を書きます。
- 取り消せない操作や、二重送信しない方がよい操作があれば書きます。

## 画像を入れる場合

画像を使う場合は、次の形式で書きます。

```markdown
![画像の説明](images/フォルダ名/画像ファイル名.png)
```

例:

```markdown
![ログイン画面](images/login/login-01.png)
```

## 解決しない場合

問い合わせ時に伝えてほしい情報を書きます。

- 氏名
- 操作していた画面名
- 発生した日時
- 利用端末
- 利用ブラウザ
- 表示されたエラーメッセージ
